About

I'm a B.Tech student in Computer Science and Engineering at VIT-AP University in Amaravati, studying since September 2023. I'm aiming for a career in software engineering, and I try to learn every layer of the stack instead of only one.

My core is data structures, algorithms and object-oriented programming, backed by coursework in DBMS, operating systems and computer networks. I apply it to real projects: React and Express apps with JWT authentication and REST APIs, FastAPI services that call an LLM, and scikit-learn models that detect phishing emails and IoT botnet traffic.

I also care about how software reaches users. I've packaged a site in Docker, built a Jenkins pipeline that deploys it to Kubernetes, and set up Nagios and Grafana to watch it run. I've also completed AWS Academy courses in cloud foundations and architecting.

I write code that is readable and easy to hand over, and I document each project with a README and a written report. I like measuring things, which is why the projects here show real numbers: accuracy, latency, build time, endpoints.

I'm looking for software engineering roles and internships, in backend, full-stack or products that use machine learning, where I can keep learning and contribute from day one.
